# 🐾 Vet Hospital Data Analysis & KPIs

## 📋 Overview
An Exploratory Data Analysis (EDA) and KPI extraction project for a veterinary clinic. Using Python, this repository processes over 4,400 appointment records to calculate 30+ strategic business metrics aimed at optimizing scheduling, daily operations, and patient retention.

## 🛠️ Tech Stack
* **Python** (Pandas, NumPy)

## 🚀 Key Features
* **Data Wrangling:** Cleaning and standardizing dates, time formats, and categorical data.
* **Operational Insights:** Identification of daily peak hours, same-day walk-in rates (39%), and scheduling bottlenecks.
* **Customer & Patient Metrics:** Calculation of client retention rates (>60%) and species/breed demographics.
* **Business Strategy:** Data-driven recommendations to improve revenue, such as dynamic pricing and preventive care memberships.
